# 🤖 JARVIS AI ASSISTANT v2.5 — Iron Man Holographic Assistant

Asistente Virtual Avanzado multitarea para Windows y Android con integración de Inteligencia Artificial, Módulos de Negocios, Control de Vehículos y Pico y Placa (Medellín, Colombia).

---

## 🌟 Características Principales

- **🤖 Inteligencia Artificial Groq (Llama-3.3-70b)**: Respuestas ultra-rápidas por voz o texto con memoria de conversación.
- **📱 Bot de Telegram Integrado**: Control remoto de tu asistente desde cualquier lugar.
- **🚨 Módulo PRIORIDAD**: Gestión de recordatorios urgentes de llamadas, mensajes y notas con alarmas repetitivas.
- **🚗 Módulo MIS VEHÍCULOS (Moto / Carro)**:
  - Control de cambio de aceite y kilometraje.
  - Historial de repuestos y mantenimientos.
  - Alerta prioritaria emergente para SOAT y Tecnomecánica.
  - **Pico y Placa Oficial Medellín, Colombia** en tiempo real.
- **💼 Módulos de Negocio**: Préstamos con intereses, Control de Parqueadero y Tienda de Tenis.
- **🎨 Interfaz HUD Iron Man v2.0**:
  - Menú compacto de 3 botones principales (`ASISTENTE`, `NEGOCIOS`, `AJUSTES`).
  - Ventanas emergentes (*Modal Popups*) con botón circular rojo neón (✕).
  - Respuesta táctil *Destello Neón (Glow Press)*.
- **💻 Ejecutable Nativo Windows (`JARVIS.exe`)**:
  - Binario GUI silencioso sin consolas negras ni destellos `cmd.exe`.
  - Ícono del **Reactor Arc** incrustado en el ejecutable y en la barra de tareas.

---

## 🚀 Inicio Rápido en Windows
Simplemente haz doble clic en **`JARVIS.exe`** en tu Escritorio o en la carpeta del proyecto.
